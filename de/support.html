Kontakt

E-Mail: voxenreader@gmail.com

Bitte nennen Sie Ihr Gerät, seine iOS- oder iPadOS-Version und die Version der App (Einstellungen → Info). Wie wir Ihre E-Mail verarbeiten: Datenschutzerklärung. Unsere Postanschrift: Impressum.

Käufe

  • Premium erscheint nicht auf Ihrem iPhone oder iPad: Prüfen Sie, ob Sie mit dem Apple Account angemeldet sind, mit dem Sie gekauft haben, und tippen Sie dann auf Einstellungen → Premium → Käufe wiederherstellen.
  • Einen Code einlösen: Einstellungen → Premium → Sie haben einen Code? Einlösen.
  • Abo ändern oder kündigen: Einstellungen → Premium → Abo verwalten oder die Anleitung von Apple.
  • Erstattungen nimmt Apple vor: Erstattung bei Apple anfordern.

Stimmen

Eine neuronale Stimme, die noch nicht installiert ist, laden Sie unter Einstellungen → Stimmen herunter.
